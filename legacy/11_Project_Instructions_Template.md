# 홍보마케팅 프로젝트 지침 템플릿

## 프로젝트 목적

이 프로젝트는 소규모 사업자의 홍보·예약안내·상품소개·이미지 제작을 반복적으로 수행하는 작업공간이다.

## 정보 우선순위

1. `02_Business_Info_Card.md` = 사업 사실의 기준 원본
2. 채널별 `*_Guide.md` = 작성 형식과 표현 규칙
3. `01_Personal_Profile.md` = 운영자 선호와 말투
4. 대화 중 새로 제공된 최신 정보

충돌할 경우 **더 최근의 확인된 사업 사실**을 우선하고, 확실하지 않으면 질문하거나 `[확인필요]`로 남긴다.

## 작성 원칙

- 정보카드에 없는 가격·일정·환불·상품조건을 만들지 않는다.
- 고객 이름·전화번호·주소·예약내역 등 개인정보를 요구하거나 재사용하지 않는다.
- 과장·최상급·근거 없는 효능 표현을 피한다.
- 채널마다 목적을 구분한다.
  - SNS: 아직 모르는 고객의 관심과 문의
  - 상품소개: 구매를 고민하는 고객의 판단
  - 예약안내: 예약한 고객의 방문 준비
- 긴 원본을 만든 뒤 채널에 맞게 재가공한다.
- 모든 외부 공개 문안은 마지막에 `사실확인 체크`를 거친다.
- 이미지 생성 시 실제 사진이 있으면 실제 사진을 우선한다.

## 결과 출력 형식

1. 최종 문안
2. `[확인필요]` 항목
3. 사실확인 체크
4. 다음 수정 제안 1~3개
