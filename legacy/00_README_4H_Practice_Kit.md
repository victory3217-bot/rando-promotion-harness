# AI 홍보·안내 4시간 실습 키트

## 교육의 핵심 구조

이 실습은 하나의 실제 사례를 처음부터 끝까지 이어서 사용하는 방식으로 진행한다.

**개인 프로필 → ChatGPT 프로젝트 → 사업정보카드 → 채널별 작성 가이드 → 결과물 생성 → 사실 검증 → 저장·재사용**

강사는 `[고마다락 주말 마사지클럽]`을 시연용 사례로 사용하고, 수강생은 자신의 사업정보를 같은 구조에 넣어 따라 한다.

## 4시간 권장 운영안

| 구간 | 시간 | 핵심 활동 | 산출물 |
|---|---:|---|---|

| 5. 안내·소개 | 40분 | 예약안내문 + 상품소개글 | 문안 2종 |
| 휴식 | 10분 |  |  |
| 6. 이미지 | 35분 | 채널별 이미지 프롬프트 + 생성/수정 | 이미지 또는 프롬프트 3종 |

## 반드시 지킬 원칙

1. AI는 초안을 만들고, 사실 확인과 최종 결정은 사업자가 한다.
2. 가격·일정·환불·상품조건은 정보카드에 없는 내용을 AI가 만들지 못하게 한다.
3. 고객 개인정보는 사업정보카드와 AI 프롬프트에 넣지 않는다.
4. 긴 문안을 먼저 만든 뒤 채널별로 줄이거나 재구성한다.
5. 결과물을 만들 때마다 사용한 정보카드와 작성 가이드를 함께 지정한다.
6. 실제 사진이 있으면 실제 사진을 우선하고, AI 이미지는 보조·초안으로 사용한다.

## 교육용 3계층 구조

- **개인 프로필**: 나는 누구이며 어떤 방식의 답변을 원하는가
- **프로젝트 지침/MD 가이드**: 이 프로젝트에서 어떤 규칙으로 작성할 것인가
- **사업정보카드**: 우리 사업의 사실은 무엇인가

세 가지를 섞지 않는 것이 핵심이다.
