# 블로그 홍보글 작성 가이드

## 목적

블로그 글의 목적은 광고 문장을 길게 늘리는 것이 아니라, **방문을 고민하는 사람이 결정을 내리는 데
필요한 정보를 충분히 제공하는 것**이다.

## 작성 원칙

1. `inputs/business-info-card.md`의 사실만 사용한다.
2. 제목에서 지역·상품·핵심 활동이 보이게 한다.
3. 첫 문단에서 누구에게 어떤 상품인지 바로 설명한다.
4. 고객이 실제로 무엇을 하고 무엇을 얻는지 구체적으로 쓴다.
5. 소요시간·가격·포함사항·운영일·예약방법 중 확인된 사실만 사용한다. 확인되지 않은 항목은
   `core/PLAYBOOK.md`의 미확정 정보 처리 원칙에 따라, 생략해도 글이 성립하면 생략하고, 생략하면
   글이 성립하지 않을 때만 사용자에게 질문한다.
6. 추천고객과 실제 프로그램 순서를 넣는다.
7. 운영자/지역 이야기는 확인된 사실만 사용한다.
8. `"특별한 경험"`, `"잊지 못할 추억"`, `"최고"`, `"유일한"` 같은 막연하거나 근거 없는 표현을 피한다.
9. 마지막에는 예약 또는 문의라는 다음 행동을 한 가지로 제시한다.
10. 확인되지 않은 정보는 `[확인필요]`로 남긴다.

## 권장 구조

1. 제목
2. 한 줄 소개
3. 이런 분께 추천
4. 무엇을 하게 되는가
5. 프로그램 순서
6. 소요시간·가격·포함사항
7. 준비물·주의사항
8. 예약·문의방법

## 이미지 가이드

블로그 이미지는 방문자가 글의 내용을 빠르게 이해하도록 돕는 **설명·증거용 시각자료**다.
실제 상품·공간 사진이 있으면 실제 사진을 우선한다.

### 기본 6요소

1. WHAT: 무엇을 보여줄 것인가
2. WHERE: 어디에서
3. WHEN: 계절·시간대
4. STYLE: 실제 사진 느낌 / 설명용 일러스트
5. RATIO: 블로그 대표 이미지나 본문 배치에 맞는 가로형 우선 검토
6. EXCLUDE: 글자·상표·로고·유명인·캐릭터 등 제외요소

### 블로그용 추가 원칙

- 실제 시설보다 넓거나 고급스럽게 과장하지 않는다.
- 프로그램의 핵심 장면을 한 이미지에 하나씩 보여준다.
- 지역·계절·작물이 실제와 맞는지 확인한다.
- 실제 사진이 있다면 AI 이미지는 분위기 컷보다 설명 보조용으로 제한한다.
- AI 이미지임을 표시할 필요가 있는 사용 상황은 운영자가 별도로 검토한다.

### 프롬프트 틀

```
[계절]의 [시간대], [지역/공간]에서 [인물]이 [실제 활동]을 하는 장면.
실제 [시설/공간 특징]과 크게 다르지 않게.
사진 느낌의 자연스러운 가로형 이미지.
글자, 로고, 상표, 유명인, 캐릭터는 넣지 마.
과장된 시설이나 실제로 제공하지 않는 물품은 넣지 마.
```
