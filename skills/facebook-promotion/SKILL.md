# 페이스북 홍보문구 작성 가이드

## 목적

페이스북에서는 사업장 소식이나 커뮤니티 이벤트를 **사람에게 이야기하듯 설명하면서 참여·문의
행동으로 연결**한다.

## 작성 원칙

1. 첫 1~2문장에 이번 게시물의 핵심 이유를 쓴다.
2. 지역·상품명·대상고객 중 최소 2개가 초반에 드러나게 한다.
3. 활동, 고객이 얻는 것, 다른 점을 구체적인 명사와 숫자로 표현한다.
4. 가격·일정·장소·예약방법 중 확인된 사실만 사용한다. 확인되지 않은 항목은 `core/PLAYBOOK.md`의
   `[확인필요]` 처리 원칙에 따라, 생략해도 게시물이 성립하면 생략하고, 생략하면 게시물이 성립하지
   않을 때만 사용자에게 질문한다.
5. 한 게시물에서 핵심 메시지는 하나만 유지한다.
6. 과장표현보다 실제 운영자의 말투를 우선한다.
7. 마지막에는 `예약`, `문의`, `댓글`, `공유` 중 가장 중요한 행동 하나만 요청한다.
8. 없는 혜택·기념품·시설·주차정보를 만들지 않는다.

## 권장 구조

- 첫 문장: 왜 지금 봐야 하는가
- 본문: 누가 / 무엇을 / 얼마나 / 무엇을 얻는가
- 사실정보: 날짜·시간·가격·장소
- 차별점 1개
- CTA 1개

## 이미지 가이드

페이스북 이미지는 게시물의 핵심 메시지를 한눈에 이해시키고 **커뮤니티 참여·문의로 연결**하는
역할을 한다.

### 기본 6요소

- WHAT: 사람/상품/행동
- WHERE: 실제 장소와 유사한 배경
- WHEN: 계절·시간
- STYLE: 실제 운영 분위기에 맞는 자연스러운 사진 느낌
- RATIO: 모바일 피드에서 보기 쉬운 정사각형 또는 세로형을 우선 검토
- EXCLUDE: 글자·로고·상표·유명인·캐릭터

### 페이스북용 추가 원칙

1. 한 이미지에 메시지를 너무 많이 넣지 않는다.
2. 사람을 넣을 경우 손·얼굴·신체 형태 오류를 확인한다.
3. 실제 행사나 프로그램에 없는 행동을 만들지 않는다.
4. 게시글의 날짜·가격·예약정보는 이미지 안에 생성시키기보다 본문 텍스트로 관리한다.
5. 실제 행사 사진이 있으면 그것을 우선 사용한다.

### 프롬프트 틀

```
[계절/시간], [실제 장소 분위기]에서 [주요고객과 유사한 인물]이 [실제 활동]을 하는 자연스러운 장면.
모바일 피드에서 보기 좋은 구도.
과장된 시설, 실제로 제공하지 않는 물품, 글자, 로고, 상표, 유명인은 넣지 마.
```

## 결과물 출력 시
