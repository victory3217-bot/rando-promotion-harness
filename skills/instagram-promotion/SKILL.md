# 인스타그램 홍보문구 작성 가이드

## 목적

인스타그램에서는 이미지와 함께 보는 사람이 빠르게 이해하도록 **핵심 활동·얻는 것·예약정보를
짧게 압축**한다.

## 꼭 들어갈 내용

1. 눈길을 끄는 첫 문장
2. 고객이 실제로 하게 될 활동
3. 고객이 얻는 경험/결과
4. 우리 상품의 핵심 특징 또는 차별점
5. 날짜·장소·가격·소요시간 중 확인된 사실만 사용한다. 확인되지 않은 항목은 `core/PLAYBOOK.md`의
   `[확인필요]` 처리 원칙에 따라, 생략해도 게시물이 성립하면 생략하고, 생략하면 게시물이 성립하지
   않을 때만 사용자에게 질문한다.
6. 예약·문의 유도
7. 필요하면 지역명·상품명 중심 해시태그

## 작성 규칙

- 본문은 5문장 이내를 기본값으로 한다.
- `"특별한 경험"`, `"잊지 못할 추억"`, `"힐링"` 같은 추상표현을 피한다.
- `"2시간"`, `"10명"`, `"1인 ○원"`처럼 확인된 숫자를 적극 사용한다.
- 해시태그는 핵심 지역·상품 중심 5개 이내.
- 콘텐츠 작성에 필요한데 언급되지 않은 내용만 `[확인필요]`로 남긴다. 필요하지 않은 내용은
  언급하지 않고 생략한다.

## 출력 형식

1. 첫 문장 후보 3개
2. 최종 본문 5문장 이내
3. 해시태그 5개 이내
4. 내가 확인할 사실 — 콘텐츠 성립에 필요한데 아직 확인되지 않은 항목이 있을 때만, 있는 만큼만
   (없으면 이 항목 자체를 생략)

## 이미지 가이드

인스타그램 이미지는 **첫 화면에서 활동과 분위기를 바로 전달**해야 한다. 실제 사진이 있으면
실제 사진을 우선한다.

### 기본 6요소

1. WHAT: 핵심 행동 하나
2. WHERE: 실제 공간과 유사한 장소
3. WHEN: 실제 운영 계절·시간대
4. STYLE: 자연스러운 사진 느낌
5. RATIO: 피드는 세로형을 우선 검토하고, 스토리/릴스용은 별도 세로 구도로 만든다
6. EXCLUDE: 글자·상표·로고·유명인·캐릭터

### 인스타그램용 추가 원칙

- 첫 이미지에서는 핵심 활동 1개만 강조한다.
- 텍스트는 이미지 생성 단계에서 넣지 않고 게시물 편집 단계에서 따로 넣는 것을 기본으로 한다.
- 실제 상품보다 지나치게 넓고 깨끗하거나 고급스러운 공간으로 만들지 않는다.
- 손가락·얼굴·도구·작물 형태를 반드시 확인한다.
- 지역·계절·복장·시설이 실제 사업과 맞는지 확인한다.

### 프롬프트 틀

```
[계절] [시간대], [실제 장소와 유사한 배경]에서 [인물]이 [핵심 활동]을 하는 순간.
자연스러운 사진 느낌, 모바일에서 활동이 크게 보이는 세로 구도.
글자, 로고, 상표, 유명인, 캐릭터는 넣지 마.
실제보다 시설을 과장하지 말고, 이번 대화에서 언급되지 않은 물품이나 서비스를 추가하지 마.
```

## 결과물 출력 시
