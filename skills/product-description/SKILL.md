# 상품소개글 작성 가이드

## 목적

상품소개글은 `살까 말까 고민하는 고객`이 읽고 판단할 수 있게 만드는 문서다.

## 고객 질문 11개 체크리스트

1. 이 상품은 한 줄로 무엇인가
2. 누구에게 추천하는가
3. 무엇을 하게 되는가
4. 무엇을 얻게 되는가
5. 프로그램 순서는 어떻게 되는가
6. 얼마나 걸리는가
7. 가격과 포함사항은 무엇인가
8. 무엇을 준비해야 하는가
9. 주의할 점은 무엇인가
10. 어떻게 예약·문의하는가
11. 운영자·지역의 확인된 이야기는 무엇인가

## 실제 작성은 7개 섹션으로 단순화

1. 상품 한 줄 소개
2. 이런 분께 추천합니다
3. 무엇을 하게 되나요
4. 프로그램 순서
5. 소요시간·가격·포함사항
6. 준비물·주의사항
7. 예약·문의방법

## 작성 규칙

- 각 섹션 2~3문장 이내.
- 없는 서비스·시설·음식·기념품을 만들지 않는다.
- 확인되지 않은 지역 역사·유래를 만들지 않는다.
- 최상급·과장표현을 사용하지 않는다.
- 정보가 없는 항목은 `[운영자확인필요]`.

## 작성 후 추가로 정리할 것

- 사실확인 필요 항목
- 고객 입장에서 아직 부족한 정보
- SNS로 줄일 때 남겨야 할 핵심 3개

## 결과물 출력 시

이 Skill로 만든 결과물에도 `core/PLAYBOOK.md`의 "채널 공통 사실검증 절차"를 항상 마지막에 적용한다.
