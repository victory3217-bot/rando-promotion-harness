# 예약안내문 작성 가이드

## 목적

예약안내문은 홍보문이 아니다. **이미 예약한 고객이 다시 전화하지 않아도 방문할 수 있게 만드는
운영문서**다.

## 필수 확인 항목

### 기본정보
1. 예약일
2. 도착시간
3. 장소
4. 주차·오시는 길

### 준비·운영
5. 준비물
6. 우천 시 운영
7. 취소·변경·환불 방법

### 연락
8. 문의 연락처
9. 늦게 도착할 때 연락방법

## 작성 규칙

- `[손님이름]`, `[예약일]`은 빈칸 템플릿으로 남긴다.
- 항목마다 줄을 바꾼다.
- 스마트폰에서 빠르게 읽히도록 짧게 쓴다.
- 없는 규정은 만들지 않는다 — `inputs/business-info-card.md`에 없으면 `[운영자확인필요]`.
- 캡처가 아니라 **글자 형태로 저장**한다.

## 출력 형식

- 제목 없이 바로 복사해 보낼 수 있는 문자
- `[손님이름]`, `[예약일]` 자리 유지
- 줄바꿈 사용
- 정보가 없으면 `[운영자확인필요]`
- 마지막에 늦을 경우 연락 안내

## 결과물 출력 시

이 Skill로 만든 결과물에도 `CLAUDE.md`의 "채널 공통 사실검증 절차"를 항상 마지막에 적용한다.
